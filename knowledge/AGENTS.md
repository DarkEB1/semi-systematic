# knowledge/

Rules for every markdown file under `knowledge/`, and for dataset READMEs under `catalog/datasets/`
and project READMEs under `research/<project>/`, which pass the same checker
(`scripts/check_frontmatter.py`, run by `just check`).

- Start from `knowledge/templates/<type>.md`. Types: context, decision, meeting, note,
  research-log, agent-log, dataset, project.
- Frontmatter, required: `id` (equals the filename stem, or the folder name for a README), `type`,
  `title`, `date` (ISO), `authors` (a list), `owner` (a handle in `context/team.yaml`).
- Frontmatter, optional: `status`, `tags` (from `context/tags.md`; a missing tag is appended there
  with a definition in the same PR), `datasets`, `related`, `project`, `private` (never on notes).
- Body: exactly one `# ` title (a line starting with `# ` inside a code fence counts too), `##`
  sections under about 400 words, relative links that resolve, no secrets, no transcripts.
- Meetings: every line under `## Decisions` links an ADR or ends with `(minor)`; actions are
  checkboxes with an `@handle` and a date.
- ADRs: `decisions/ADR-NNNN-<slug>.md` with the next free number. A changed decision is a new ADR
  and the old one gets `status: superseded`.
- Never rename or move a file here. `INDEX.md` is generated by `just index`; do not edit it by hand.
- Agent-log entries (`agent-log/`) link every file the task touched and every file it relied on;
  a loop appends all its iterations to one entry.
